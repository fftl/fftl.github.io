## 이산확률분포

- 딱 한 번만 한다 -> **베르누이**    
- 여러 번 던져서 나온 횟수 (다시 넣음) -> **이항**
- 여러 번 뽑아서 나온 횟수 (다시 안 넣음) -> **초기하**
- 처음 성공할 때까지 걸린 횟수 -> **기하**
- 정해진 시간/공간 속 발생 횟수 -> **포아송**

## **시험장 직행 요약 노트**

- **평균 비교할 때:** 표본 많으면 Z(표준정규), 표본 적으면 **t-분포**
- **비율/독립성 검정할 때 (범주형 데이터):** **카이제곱($\chi^2$)분포**
- **두 집단 분산 비교 or 세 집단 이상 평균 비교(ANOVA):** **F-분포**
- **사건이 일어날 때까지 걸리는 "시간":** **지수분포**

## 변수 선택(Feature Selection)

빅데이터 분석기사 시험에서 **변수 선택(Feature Selection)은 모델의 성능을 좌우하는 아주 중요한 단계이며, 매 회차 빠지지 않고 출제되는 핵심 파트입니다.

수많은 데이터(변수) 중에서 진짜 정답을 맞히는 데 도움이 되는 **'똘똘한 변수'만 골라내는 작업**을 말합니다. 불필요한 변수가 너무 많으면 모델의 학습 속도가 느려지고, 오히려 성능이 떨어지는 **'차원의 저주(Curse of Dimensionality)'**에 빠지거나 과적합(Overfitting)이 발생할 수 있기 때문입니다.

변수 선택 방법은 크게 **3가지 기법(필터, 래퍼, 임베디드)**으로 나뉩니다. 시험에서는 이 3가지를 구분하고, 각각에 속하는 방법론을 묻는 문제가 자주 나옵니다.

---

### 1. 필터 기법 (Filter Method) : "통계 점수로 줄 세우기"

머신러닝 모델에 데이터를 넣기 **전(Pre-processing)에**, 통계적인 측정값을 이용해 변수들의 순위를 매기고 하위권 변수들을 1차적으로 걸러내는(Filter) 방법입니다.

- **특징:** 특정 머신러닝 모델의 종류에 구애받지 않으며, 계산 속도가 매우 빠릅니다.
    
- **대표적인 방법:**
    
    - **상관계수 (Correlation):** 변수 간의 선형적 연관성이 높은 것들을 찾아냅니다. (예: A변수와 B변수가 거의 똑같은 의미라면 하나만 남김)
        
    - **카이제곱 검정 (χ2 Test):** 독립변수와 종속변수(정답) 간의 독립성을 검정하여 유의미한 변수를 찾습니다.
        
    - **정보 이득 (Information Gain):** 어떤 변수가 정답을 맞히는 데 불확실성을 얼마나 줄여주는지(엔트로피 감소) 계산합니다.
        

### 2. 래퍼 기법 (Wrapper Method) : "직접 모델에 넣어보고 평가하기" 🌟 (빈출)

변수들의 묶음(Subset)을 요리조리 바꿔가며 **실제 예측 모델에 반복적으로 학습을 시켜보고**, 가장 성능이 좋게 나오는 최적의 변수 조합을 찾는 방법입니다.

- **특징:** 변수 조합을 계속 바꿔가며 모델을 여러 번 돌려야 하므로 **시간과 비용이 가장 오래 걸리지만, 정확도는 가장 높습니다.**
    
- **대표적인 방법 (매우 중요):**
    
    - **전진 선택법 (Forward Selection):** 아무 변수도 없는 빈 상태에서 시작하여, **가장 성능을 많이 높여주는 변수부터 하나씩 차례대로 추가**하는 방법입니다. 한 번 추가된 변수는 뺄 수 없습니다.
        
    - **후진 제거법 (Backward Elimination):** 모든 변수를 전부 다 넣은 꽉 찬 상태에서 시작하여, **가장 쓸모없는(영향력이 적은) 변수부터 하나씩 빼버리는** 방법입니다. 한 번 제거된 변수는 다시 넣을 수 없습니다.
        
    - **단계적 선택법 (Stepwise Selection):** 전진 선택법과 후진 제거법을 합친 방식입니다. 변수를 하나씩 추가하되, 새로 들어온 변수 때문에 기존에 있던 변수의 중요도가 떨어지면 그 변수를 다시 빼버립니다. 가장 유연하고 실무에서 많이 쓰입니다.
        

### 3. 임베디드 기법 (Embedded Method) : "학습하면서 스스로 선택하기"

모델이 **학습(Training)을 하는 과정 안에 변수 선택 기능이 아예 내장(Embedded)**되어 있는 방법입니다. 필터 기법의 '빠른 속도'와 래퍼 기법의 '높은 정확도'라는 장점을 합쳤습니다.

- **특징:** 모델 자체적으로 어떤 변수가 중요한지 가중치를 조절하며 학습합니다.
    
- **대표적인 방법:**
    
    - **라쏘 회귀 (Lasso / L1 규제):** 예측에 도움이 안 되는 불필요한 변수의 가중치를 **아예 0으로** 만들어 버립니다. (즉, 모델이 스스로 변수를 지워버리는 효과)
        
    - **릿지 회귀 (Ridge / L2 규제):** 불필요한 변수의 가중치를 0에 가깝게 아주 작게 줄여버립니다. (0으로 만들지는 않으므로 변수 자체가 삭제되지는 않음)
        
    - **엘라스틱 넷 (Elastic Net):** 라쏘(L1)와 릿지(L2)의 장점을 결합한 방식입니다.
        
    - **의사결정나무의 변수 중요도 (Feature Importance):** 랜덤포레스트 같은 트리 기반 모델들은 내부적으로 불순도를 기준으로 변수를 분기하기 때문에, 자동으로 어떤 변수가 중요한지 수치화해서 보여줍니다.

## 차원축소

방금 전 살펴본 '변수 선택(Feature Selection)'이 기존 데이터에서 쓸모없는 기둥(컬럼)을 버리고 알짜배기만 그대로 '고르는' 작업이었다면, 이번에 알아볼 **차원 축소(Dimensionality Reduction)** 파트의 핵심인 '특징 추출(Feature Extraction)'은 기존 변수들을 지지고 볶아서 **완전히 새로운 엑기스 변수**를 만들어내는 방법입니다.

빅데이터 분석기사 시험에서는 크게 **선형 기법**과 **비선형 기법**을 구분하고, 각 방법의 고유한 특징을 묻는 문제가 자주 출제됩니다. 핵심 위주로 요약해 드릴게요.

---

### 1. 선형 차원 축소 기법

데이터의 분포가 비교적 직선적이고 평탄한 구조를 가질 때 사용하는 방법들입니다.

- **주성분 분석 (PCA, Principal Component Analysis)**
    
    - **특징:** 가장 대표적인 '비지도 학습' 기반 차원 축소 방법입니다.
        
    - **핵심 원리:** 데이터가 가장 넓게 퍼져 있는(분산이 가장 큰) 방향을 찾아서 첫 번째 축(제1주성분)으로 삼고, 그 다음으로 분산이 큰 직교하는 방향을 제2주성분으로 삼아 데이터를 투영시킵니다.
        
    - **출제 포인트:** "데이터의 정보(분산) 손실을 최소화한다", "변수 간의 상관관계(다중공선성)를 제거할 수 있다"는 지문이 나오면 무조건 PCA입니다.
        
- **선형 판별 분석 (LDA, Linear Discriminant Analysis)**
    
    - **특징:** PCA와 원리는 비슷하지만, **'지도 학습'** 기반이라는 점이 가장 강력한 차이점입니다.
        
    - **핵심 원리:** 정답(클래스) 데이터를 활용합니다. 서로 다른 클래스(예: 합격자 vs 불합격자)끼리는 최대한 멀리 떨어뜨리고, 같은 클래스끼리는 최대한 오밀조밀하게 뭉치도록 축을 찾습니다.
        
    - **출제 포인트:** "클래스 간 분산은 최대화하고, 클래스 내 분산은 최소화한다"는 지문이 핵심입니다.
        
- **특이값 분해 (SVD, Singular Value Decomposition)**
    
    - **특징:** 행렬 분해라는 수학적 기법을 이용해 데이터의 핵심 뼈대만 남깁니다.
        
    - **핵심 원리:** 크기가 큰 m x n 행렬을 3개의 작은 행렬로 쪼개어 가장 중요한 정보(특이값)만 추출합니다.
        
    - **출제 포인트:** 추천 시스템(예: 넷플릭스 영화 추천)의 협업 필터링이나 텍스트 마이닝, 이미지 압축 등에 쓰인다는 점을 기억하시면 좋습니다.
        

### 2. 비선형 차원 축소 기법

데이터가 마치 스위스 롤 빵처럼 복잡하게 꼬여 있거나 말려 있는 비선형적 구조일 때, 이를 쫙 펴서 저차원으로 내리는 방법들입니다.

- **다차원 척도법 (MDS, Multidimensional Scaling)**
    
    - **핵심 원리:** 원본 고차원 공간에서 데이터 객체들 사이에 측정된 **'거리(유사도)'**를 저차원 공간에서도 최대한 똑같이 유지하도록 점들을 배치합니다.
        
    - **출제 포인트:** "객체 간의 상대적 거리를 보존한다", "유사성을 시각화한다"는 키워드가 나옵니다.
        
- **t-SNE (t-Distributed Stochastic Neighbor Embedding)**
    
    - **핵심 원리:** 고차원에서 가까이 있던 데이터는 저차원에서도 가깝게, 고차원에서 멀리 있던 데이터는 저차원에서도 멀어지도록 '확률'을 이용해 배치합니다.
        
    - **출제 포인트:** 데이터 간의 군집(Cluster)을 화면에 2D나 3D로 보여주는 **'시각화'에 가장 압도적으로 뛰어난 방법**입니다. 복잡한 비선형 데이터를 시각화한다고 하면 t-SNE를 고르시면 됩니다.
        
- **오토인코더 (Autoencoder)**

**💡 시험장 직행 요약 노트**

- 가장 기본적이고 분산 최대화 지향 (비지도) $\rightarrow$ **PCA**
    
- 정답을 알고 있고 클래스 분리 지향 (지도) $\rightarrow$ **LDA**
    
- 군집 파악을 위한 2D/3D 시각화 끝판왕 $\rightarrow$ **t-SNE**
    
- 신경망을 이용한 인코더-디코더 압축 $\rightarrow$ **오토인코더**
