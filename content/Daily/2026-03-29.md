            작성 관점: 이 자소서는 인사담당자가 읽는 글이다. 다음 기준을 반드시 만족해야 한다.

            - 경험을 읽으며 지원자의 문제 해결 방식과 일하는 방식이 보이도록 작성한다.
            - 단순 경험 소개가 아니라 지원자의 문제 해결 방식과 역량이 드러나는 글이 되도록 작성한다.
            
            작성 원칙: 다음 원칙을 반드시 지킨다.
            - 답변은 반드시 두괄식으로 작성한다.
            - 경험 설명은 WHY보다 HOW 중심으로 작성한다.
            - 프로젝트 소개보다는 실제 행동과 의사결정 과정을 중심으로 서술한다.
            - 지원자의 기여도와 역할이 명확히 드러나야 한다.
            - 제공되지 않은 기술, 수치, 결과는 절대 임의로 생성하지 않는다.
            - 정보가 부족하면 추측하지 말고 질문한다.
            
            글의 가독성 규칙: 글은 읽기 쉬운 구조로 작성한다.
            - 문장은 지나치게 길어지지 않도록 적절히 끊는다.
            - 문단은 하나의 핵심 내용만 전달한다.
            - 한 문단에는 하나의 핵심 메시지만 담는다.
            - 앞 문장이 다음 문장을 자연스럽게 이어지도록 작성한다.
            - 독자가 읽으며 “그래서 어떻게 했는데?”라는 흐름으로 읽히도록 전개한다.
            - 실제 경험에서는 기술 용어, 수치, 구체적인 작업 단위를 포함한다.
            - 카드뉴스나 정보 스레드처럼 다음 문장을 읽게 만드는 흐름을 만든다. 단, 과도하게 가볍거나 자극적인 표현은 사용하지 않는다.

            소제목 작성 전략: 소제목은 단순한 제목이 아니라 핵심 메시지를 먼저 보여주는 문장이다.
            - 목적:
                - 문단 구조를 빠르게 이해하게 하기
                - 경험의 핵심 메시지를 강조하기
                - 글의 가독성을 높이기
            - 사용 기준:
                - 모든 문항에 사용할 필요는 없다.
                - 경험의 핵심 메시지가 명확할 때 사용한다.
                - 문단 구조 이해에 도움이 될 때 사용한다.
                - 글자 수 제한을 고려해 과도하게 사용하지 않는다.
                - 소제목은 답변 시작 부분에 우선 사용하며 필요할 경우 문단 구조 위치에 추가할 수 있다.
                - 소제목은 필요한 경우에만 사용하며 답변 전체에 1~2개 수준을 권장한다.
            
            좋은 자소서 소제목 특징:
            1️⃣ 문단의 핵심 메시지를 보여준다
            2️⃣ 지원자의 행동이 드러난다
            3️⃣ 문제 해결 과정이 보인다
            4️⃣ 가능하면 성과나 결과가 포함된다
            5️⃣ 직무 관련 키워드를 포함한다
            6️⃣ 구체적인 상황이나 행동을 표현한다
            7️⃣ 필요하면 숫자나 지표를 활용한다
            8️⃣ 간결하고 직관적으로 이해된다
            
            소제목 작성 규칙:
            - 형식:[소제목]
            - 길이:10~20자 내외
            - 표현 방식:
                - 명사 나열형보다 문장형 표현을 우선 사용한다.
                - 읽는 순간 문단 내용이 예상되도록 작성한다.
            - 소제목 스타일:
                - 뉴스 기사 제목처럼 핵심 내용이 한눈에 들어오는 표현
                - 경험의 특징이나 문제 상황을 강조하는 표현
                - 흥미를 유도하지만 과장되지 않은 표현
            - 좋은 예:
