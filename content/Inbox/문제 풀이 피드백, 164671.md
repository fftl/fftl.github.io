### 현재 구조

sql

```sql
FROM USED_GOODS_FILE A,
     (SELECT BOARD_ID
      FROM USED_GOODS_BOARD A,
           (SELECT MAX(VIEWS) AS VIEWS
            FROM USED_GOODS_BOARD) B
      WHERE B.VIEWS = A.VIEWS) B
```

**중첩 레벨:**

1. 최외곽: FILE 테이블
2. 2단계: 최고 조회수 게시글의 BOARD_ID 찾기
3. 3단계: 최고 조회수 값 찾기

**문제점:**

- 3단계 중첩 (복잡)
- BOARD 테이블 2번 스캔

## 개선 방법

### 방법 1: 단일 서브쿼리 (추천!)

sql

```sql
SELECT '/home/grep/src/' || F.BOARD_ID || '/' || F.FILE_ID || F.FILE_NAME || F.FILE_EXT AS FILE_PATH
FROM USED_GOODS_FILE F
WHERE F.BOARD_ID = (
    SELECT BOARD_ID
    FROM USED_GOODS_BOARD
    WHERE VIEWS = (SELECT MAX(VIEWS) FROM USED_GOODS_BOARD)
)
ORDER BY F.FILE_ID DESC;
```

**개선점:**

- 중첩 줄임 (2단계만)
- 가독성 향상
- 성능 비슷

### 방법 2: JOIN 방식 (명확함)

sql

```sql
SELECT '/home/grep/src/' || F.BOARD_ID || '/' || F.FILE_ID || F.FILE_NAME || F.FILE_EXT AS FILE_PATH
FROM USED_GOODS_FILE F
INNER JOIN USED_GOODS_BOARD B ON F.BOARD_ID = B.BOARD_ID
WHERE B.VIEWS = (SELECT MAX(VIEWS) FROM USED_GOODS_BOARD)
ORDER BY F.FILE_ID DESC;
```

**장점:**

- JOIN 조건 명확
- 서브쿼리 1단계만
- 실무에서 선호

### 방법 3: 윈도우 함수 (고급)

sql

```sql
SELECT '/home/grep/src/' || F.BOARD_ID || '/' || F.FILE_ID || F.FILE_NAME || F.FILE_EXT AS FILE_PATH
FROM USED_GOODS_FILE F
INNER JOIN (
    SELECT BOARD_ID,
           RANK() OVER (ORDER BY VIEWS DESC) AS RNK
    FROM USED_GOODS_BOARD
) B ON F.BOARD_ID = B.BOARD_ID
WHERE B.RNK = 1
ORDER BY F.FILE_ID DESC;
```

**장점:**

- 동점자 처리 유연
- 확장성 좋음 (TOP N 쉽게 변경)

### 방법 4: FETCH FIRST (Oracle 12c+)

sql

```sql
SELECT '/home/grep/src/' || F.BOARD_ID || '/' || F.FILE_ID || F.FILE_NAME || F.FILE_EXT AS FILE_PATH
FROM USED_GOODS_FILE F
WHERE F.BOARD_ID IN (
    SELECT BOARD_ID
    FROM USED_GOODS_BOARD
    ORDER BY VIEWS DESC
    FETCH FIRST 1 ROWS ONLY
)
ORDER BY F.FILE_ID DESC;
```

**가장 간결!**

## LEE의 패턴 분석

**LEE는 서브쿼리를 선호하는 것 같아요:**

**장점:**

- 단계별 논리가 명확
- 독립적인 서브쿼리로 테스트 쉬움

**단점:**

- 중첩이 깊어지면 복잡
- 가독성 떨어질 수 있음

**개선 방향:**

1. 중첩을 줄이기 (2단계 이하)
2. JOIN과 적절히 섞어 쓰기
3. 복잡하면 WITH절 (CTE) 고려

## WITH절 (CTE) 예시

**복잡한 쿼리는 이렇게:**

sql

```sql
WITH MAX_VIEW_BOARD AS (
    SELECT BOARD_ID
    FROM USED_GOODS_BOARD
    WHERE VIEWS = (SELECT MAX(VIEWS) FROM USED_GOODS_BOARD)
)
SELECT '/home/grep/src/' || F.BOARD_ID || '/' || F.FILE_ID || F.FILE_NAME || F.FILE_EXT AS FILE_PATH
FROM USED_GOODS_FILE F
INNER JOIN MAX_VIEW_BOARD M ON F.BOARD_ID = M.BOARD_ID
ORDER BY F.FILE_ID DESC;
```
