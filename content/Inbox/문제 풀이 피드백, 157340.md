**1. LEFT JOIN 개념 정확**

sql

```sql
WHERE A.CAR_ID = B.CAR_ID(+)
```

- 모든 차량 조회 + 대여중인 차량 매칭
- Oracle 전통 방식 정확

**2. 날짜 범위 조건 완벽**

sql

```sql
WHERE END_DATE >= DATE '2022-10-16' 
  AND START_DATE <= DATE '2022-10-16'
```

- 10월 16일에 대여중인 경우 정확히 필터링
- 시작일 ≤ 기준일 ≤ 종료일

**3. CASE WHEN 로직 정확**

sql

```sql
CASE
    WHEN B.CAR_ID IS NULL THEN '대여 가능'
    ELSE '대여중'
END
```

- NULL 체크로 대여 여부 판단

**4. DISTINCT로 중복 제거**

sql

```sql
SELECT DISTINCT(CAR_ID)
```

- 차량 목록 중복 없이

## 개선 방법 3가지

### 방법 1: 단순화 (추천!)

**LEE의 서브쿼리 제거 가능:**

sql

```sql
SELECT CAR_ID,
       CASE 
           WHEN MAX(CASE 
                       WHEN START_DATE <= DATE '2022-10-16' 
                        AND END_DATE >= DATE '2022-10-16' 
                       THEN 1 
                       ELSE 0 
                   END) = 1 
           THEN '대여중'
           ELSE '대여 가능'
       END AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC;
```

**동작 원리:**

1. 각 차량별 대여 기록 그룹화
2. 10월 16일에 대여중이면 1, 아니면 0
3. MAX로 하나라도 1이면 대여중

### 방법 2: ANSI JOIN (가독성)

sql

```sql
SELECT A.CAR_ID,
       CASE 
           WHEN B.CAR_ID IS NULL THEN '대여 가능'
           ELSE '대여중'
       END AS AVAILABILITY
FROM (
    SELECT DISTINCT CAR_ID
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
) A
LEFT JOIN (
    SELECT CAR_ID
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE START_DATE <= DATE '2022-10-16'
      AND END_DATE >= DATE '2022-10-16'
) B ON A.CAR_ID = B.CAR_ID
ORDER BY A.CAR_ID DESC;
```

**LEE 코드와 동일하지만:**

- ANSI 표준 문법
- 가독성 향상

### 방법 3: EXISTS (효율적)

sql

````sql
SELECT DISTINCT CAR_ID,
       CASE 
           WHEN EXISTS (
               SELECT 1
               FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY H2
               WHERE H2.CAR_ID = H1.CAR_ID
                 AND H2.START_DATE <= DATE '2022-10-16'
                 AND H2.END_DATE >= DATE '2022-10-16'
           )
           THEN '대여중'
           ELSE '대여 가능'
       END AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY H1
ORDER BY CAR_ID DESC;
```

**EXISTS의 장점:**
- 하나만 찾으면 바로 중단 (빠름)
- 상관 서브쿼리

## 날짜 범위 조건 상세 설명

**"10월 16일에 대여중"의 의미:**
```
대여 기간: [START_DATE -------- END_DATE]
기준일:                 2022-10-16

조건: START_DATE <= 2022-10-16 <= END_DATE
```

**예시:**
```
1. START: 10-11, END: 10-16 → 대여중 ✅
2. START: 10-16, END: 10-20 → 대여중 ✅
3. START: 10-15, END: 10-17 → 대여중 ✅
4. START: 10-17, END: 10-20 → 대여 가능 ❌
5. START: 10-10, END: 10-15 → 대여 가능 ❌
````

**SQL 조건:**

sql

```sql
START_DATE <= DATE '2022-10-16'  -- 시작이 16일 이전
AND END_DATE >= DATE '2022-10-16'  -- 종료가 16일 이후
```

## DISTINCT(컬럼) 참고

**LEE 코드:**

sql

```sql
SELECT DISTINCT(CAR_ID)
```

**Oracle에서:**

- `DISTINCT(CAR_ID)`는 `DISTINCT CAR_ID`와 같음
- 괄호는 의미 없음 (함수가 아님)

**올바른 표기:**

sql

```sql
SELECT DISTINCT CAR_ID  -- 괄호 없이
```

**여러 컬럼:**

sql

```sql
SELECT DISTINCT CAR_ID, START_DATE  -- 괄호 없음
```

## 실전 활용

### 특정 기간 대여 가능 차량

sql

```sql
SELECT CAR_ID,
       CASE 
           WHEN MAX(CASE 
                       WHEN START_DATE <= DATE '2022-10-20'
                        AND END_DATE >= DATE '2022-10-16'
                       THEN 1 ELSE 0 
                   END) = 1
           THEN '대여중'
           ELSE '대여 가능'
       END AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
HAVING MAX(CASE 
              WHEN START_DATE <= DATE '2022-10-20'
               AND END_DATE >= DATE '2022-10-16'
              THEN 1 ELSE 0 
          END) = 0  -- 대여 가능한 것만
ORDER BY CAR_ID;
```

### 차량별 대여 상태 + 최근 대여일

sql

```sql
SELECT CAR_ID,
       CASE 
           WHEN MAX(CASE 
                       WHEN START_DATE <= DATE '2022-10-16'
                        AND END_DATE >= DATE '2022-10-16'
                       THEN 1 ELSE 0 
                   END) = 1
           THEN '대여중'
           ELSE '대여 가능'
       END AS AVAILABILITY,
       MAX(END_DATE) AS 최근반납일
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC;
```

### 대여중인 차량의 반납 예정일

sql

```sql
SELECT A.CAR_ID,
       '대여중' AS AVAILABILITY,
       B.END_DATE AS 반납예정일
FROM (SELECT DISTINCT CAR_ID
      FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY) A
INNER JOIN (SELECT CAR_ID, END_DATE
            FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
            WHERE START_DATE <= DATE '2022-10-16'
              AND END_DATE >= DATE '2022-10-16') B
ON A.CAR_ID = B.CAR_ID
ORDER BY A.CAR_ID DESC;
```
