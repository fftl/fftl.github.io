어원(root)에 접미사(suffix)가 붙어서 단어가 만들어지는데, 접미사에 따라 품사가 결정됩니다.

## 기본 구조

**어근(root) + 접미사(suffix) = 새로운 단어**

예: develop(발전시키다) + ment = development(발전, 명사)

## 명사를 만드는 접미사

**-ment**: 동사 뒤에 붙어 "~하는 것, ~한 상태"라는 명사를 만듦

- develop → development (발전)
- manage → management (관리)

**-tion/-sion**: 동사 뒤에 붙어 "~하는 행위, 결과"를 나타내는 명사

- create → creation (창조)
- decide → decision (결정)

**-ness**: 형용사 뒤에 붙어 "~한 상태"라는 명사

- happy → happiness (행복)
- kind → kindness (친절)

**-er/-or**: 동사 뒤에 붙어 "~하는 사람/것"

- teach → teacher (선생님)
- act → actor (배우)

## 형용사를 만드는 접미사

**-ive**: "~하는 경향이 있는"

- create → creative (창의적인)
- act → active (활동적인)

**-al/-ial**: "~와 관련된"

- nation → national (국가의)
- education → educational (교육의)

**-ed**: 과거분사 형태로 "~된, ~받은" (수동/완료의 느낌)

- interest → interested (흥미를 느끼는)
- excite → excited (흥분한)

**-ing**: 현재분사 형태로 "~하는, ~시키는" (능동/진행의 느낌)

- interest → interesting (흥미로운)
- excite → exciting (흥분시키는)

## 동사를 만드는 접미사

**-ize/-ise**: "~하게 만들다, ~화하다"

- real → realize (깨닫다, 실현하다)
- modern → modernize (현대화하다)

**-en**: "~하게 하다"

- weak → weaken (약화시키다)
- dark → darken (어둡게 하다)

## 실제 적용 예시

**organize (동사: 조직하다)**

- organiz**ation** → 명사 (조직)
- organiz**ed** → 형용사 (조직적인, 정돈된)
- organiz**ing** → 형용사/명사 (조직하는)

**national (형용사: 국가의)**

- nation**alize** → 동사 (국유화하다)
- nation**alization** → 명사 (국유화)

## 실용 팁

1. **-tion, -ment, -ness**가 보이면 → 명사
2. **-ive, -al, -ed, -ing**이 보이면 → 형용사 (또는 명사로도 쓰임)
3. **-ize, -en**이 보이면 → 동사

단어를 볼 때 어근을 먼저 파악하고, 뒤에 뭐가 붙었는지 확인하면 의미를 유추할 수 있습니다.
