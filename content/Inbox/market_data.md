# 개요
공공데이터 포털에서 가장 수요가 있는 [소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do) 데이터를 이용해 인덱스의 유무에 따른 조회 성능 테스트를 진행하는 프로젝트입니다.

전국의 데이터를 모두 사용하기에는 너무 큰 데이터라 가장 관심이 높은 지역인 서울 데이터를 기준으로 프로젝트를 진행합니다.

![[market_data-1766128874437.png]]

# 사용 기술
사용 기술은 다음과 같습니다.
- python, fastapi
	- pandas
	- jupyter notebook
- vue.js, typescript

# 진행
- to_sql을 통해 그대로 생성한 뒤 조회 및 성능 테스트

### 먼저 인덱스 단순 테스트
**160,879건의 데이터**를 가지고 단순하게 인덱스가 있을 때와 없을 때의 비교를 해보았습니다.![[market_data-1766151017445.png]] 
이런 식의 데이터를 가지고 있는 상황에서, 다음 코드를 통해 상가업소번호의 인덱스가 있을 때, 없을 때의 **EXPLAIN ANALYZE를 통해 인덱스의 위력**을 비교해보고자 합니다.

![[market_data-1766151367305.png]]
먼저 **인덱스가 없는 상황**에서의 결과 값입니다.
```
-> Filter: (wild_data.`상가업소번호` = 'MA010120220813990220')  (cost=18160 rows=15610) (actual time=0.0663..286 rows=1 loops=1)
    -> Table scan on wild_data  (cost=18160 rows=156101) (actual time=0.0584..248 rows=160879 loops=1)
```

다음은 **인덱스가 존재하는 상황**에서의 결과 값입니다.
```
-> Filter: (wild_data.`상가업소번호` = 'MA010120220813990220')  (cost=0.672 rows=1) (actual time=0.0365..0.0397 rows=1 loops=1)
    -> Index lookup on wild_data using 상가업소번호_idx (상가업소번호='MA010120220813990220')  (cost=0.672 rows=1) (actual time=0.0345..0.0377 rows=1 loops=1)
```

보시다시피 아래 결과에서는 `상가업소번호_idx`를 이용한 것이 보이며 

비용이 18160 -> 0.672로
시간이 248ms -> 0.0377ms 
읽은 행 수 160879row -> 1row 이라는 결과를 통해 극적으로 비용과 시간이 줄어든 것을 확인할 수 있었습니다.
