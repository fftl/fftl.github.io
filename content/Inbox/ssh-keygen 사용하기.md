
### 키 생성하기
``` bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_name -C "github-actions"
```

### 생성 명령어 설명

| 옵션                       | 의미           | 설명                        |
| ------------------------ | ------------ | ------------------------- |
| `ssh-keygen`             | SSH 키 생성 도구  | SSH 키 쌍(공개키+개인키)을 만드는 명령어 |
| `-t`                     | type (타입)    | 암호화 알고리즘 종류 지정            |
| `ed25519`                | 알고리즘 이름      | 최신 암호화 방식 (빠르고 안전함)       |
| `-f`                     | 파일명 지정       | 직접 키 파일의 이름을 지정 (생략 가능)   |
| `~/.ssh/id_ed25519_name` | 파일명 내용       | 키의 이름 입력                  |
| `-C`                     | Comment (주석) | 키에 메모 추가 (누가/언제/왜 만들었는지)  |
| `"github-actions"`       | 주석 내용        | 이 키의 용도 표시                |

| 파일                   | 공개 가능?    | 저장 위치               |
| -------------------- | --------- | ------------------- |
| **개인키** (id_ed25519) | ❌ 절대 안 됨! | 로컬, GitHub Secrets만 |
| **공개키** (.pub)       | ✅ 공개 OK   | 서버, GitHub 등 어디든    |

### 사용하기

- 이름과 같이 공개되어도 괜찮은 공개키를 연결이 필요한 서버의 `~/.ssh` 위치에 생성해줍니다. 이 행동은 **`해당 서버에 도어락을 거는 것`** 이라고 이해할 수 있습니다.
- 이제 해당 서버에 접근할 때에 개인키를 사용해야 합니다. 개인키는 절대 public한 공간에 게시해서는 안되며 개인의 로컬이나, github의 secrets에만 입력하여 사용합니다. 위에서 만든 **`도어락을 열기 위한 비밀번호`** 라고 이해할 수 있습니다.
