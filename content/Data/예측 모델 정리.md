### 1. **XGBoost** 

python

```python

xgb = XGBClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=5
)
xgb.fit(X_train, y_train)
```

**특징**:
- 랜덤포레스트보다 **성능이 더 좋은 경우가 많음**
- Gradient Boosting 방식 (이전 트리의 실수를 다음 트리가 보완)
- Kaggle 대회에서 가장 많이 우승
- 속도도 빠름 (병렬 처리)

**장점**: 높은 정확도, 빠른 속도 
**단점**: 하이퍼파라미터가 복잡, 과적합 주의

## 실전 비교 코드

python
````python
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier

# 데이터 생성
X, y = make_classification(n_samples=1000, n_features=20, random_state=42)

# 모델들
models = {
    '랜덤포레스트': RandomForestClassifier(n_estimators=100, random_state=42),
    'XGBoost': XGBClassifier(n_estimators=100, random_state=42, verbosity=0),
    'LightGBM': LGBMClassifier(n_estimators=100, random_state=42, verbose=-1)
}

# 성능 비교
print("=== 교차 검증 점수 (5-Fold) ===")
for name, model in models.items():
    scores = cross_val_score(model, X, y, cv=5)
    print(f"{name:15s}: {scores.mean():.4f} (±{scores.std():.4f})")

# 학습 시간 비교
import time
print("\n=== 학습 시간 ===")
for name, model in models.items():
    start = time.time()
    model.fit(X, y)
    elapsed = time.time() - start
    print(f"{name:15s}: {elapsed:.4f}초")
```

**출력 예시:**
```
=== 교차 검증 점수 (5-Fold) ===
랜덤포레스트      : 0.9180 (±0.0234)
XGBoost          : 0.9280 (±0.0198)
LightGBM         : 0.9260 (±0.0212)

=== 학습 시간 ===
랜덤포레스트      : 0.2314초
XGBoost          : 0.1523초
LightGBM         : 0.0856초
````

## 어떤 모델을 선택할까?

python
```python
# 상황별 추천

# 1. 처음 시작 / 빠른 프로토타입
→ 랜덤포레스트 (간단, 안정적)

# 2. 최고 성능 필요 / Kaggle 대회
→ XGBoost, LightGBM, CatBoost 중 하나 (앙상블도 고려)

# 3. 대용량 데이터 (수백만 행)
→ LightGBM (빠른 속도)

# 4. 범주형 변수 많음
→ CatBoost (자동 처리)

# 5. 해석 필요 / 규제 산업
→ 로지스틱 회귀, 단일 결정 트리

# 6. 작은 데이터 (<1000개)
→ SVM, 로지스틱 회귀

# 7. 이미지/텍스트/시계열
→ 신경망 (CNN, RNN, Transformer)
```

## 정리

**랜덤포레스트의 위치**:
- 성능: 상위권 (트리 기반 모델 중 기본)
- 안정성: 매우 좋음
- 사용 편의성: 쉬움
- 대중성: 매우 높음

**더 나은 성능**:
- XGBoost, LightGBM, CatBoost (부스팅 계열)
- 하지만 튜닝이 더 필요
