Lock 모드에 대한 설명이 쉽게 와닿지 않아서, 클러드에게 쉽게 정리를 부탁했습니다.
## Lock 모드 쉬운 설명

### 1. **Null** (Lock 없음)

- 아무도 안 쓰는 상태
- 모두와 호환 (O 전부)

### 2. **RS (Row Share)**

- **"나 이 테이블 읽을 건데, 특정 row는 나중에 수정할 수도 있어"**
- `SELECT ... FOR UPDATE` 할 때
- 다른 사람들도 읽기 가능 (RS, RX, S, SRX 허용)
- 단, 테이블 전체 수정(X)은 막음

### 3. **RX (Row Exclusive)** ★ 가장 흔함

- **"나 이 테이블의 특정 row들을 수정 중이야"**
- `INSERT`, `UPDATE`, `DELETE` 할 때
- 다른 사람들도 각자 row 수정 가능 (RS, RX 허용)
- 테이블 전체 읽기/수정(S, SRX, X)은 막음

### 4. **S (Share)**

- **"나 이 테이블 전체를 읽는 중이야. 아무도 수정하지 마"**
- 특수한 경우(테이블 전체 일관성 보장 필요)
- 다른 사람 읽기만 가능 (Null, RS, S만 허용)
- 수정(RX, SRX, X) 전부 막음

### 5. **SRX (Share Row Exclusive)**

- **"나 테이블 전체 읽으면서, 특정 row는 수정할 거야"**
- S + RX 결합
- 거의 안 쓰임

### 6. **X (Exclusive)**

- **"나 이 테이블 전체를 독점해. 아무도 건드리지 마"**
- `ALTER TABLE`, `DROP TABLE` 등 DDL 할 때
- 다른 모든 작업 막음 (전부 X)
