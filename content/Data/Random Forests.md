랜덤 포레스트

- 데이터 샘플링
	- 데이터를 가지고 내가 설정한(n_estimators) 개수 만큼의 결정 트리를 만들어 냅니다.
	- 결정 트리가 많아질 수록 안정적으로 예측할 수 있는 확률이 올라갑니다.
- 특성 선택
	- 일부의 특성을 랜덤하게 선택하여 분할 기준을 결정합니다.

랜덤포레스트는 수많은 결정 트리를 만들어서 모델을 만들고, 각각의 결정트리들의 예측을 다수결로 최종 예측을 하게 됩니다. 여기서 결정트리의 개수를 n_estimators로 설정할 수 있는데, 결정트리 개수가 높아질수록 안정적인 예측을 할 수 있습니다. 

결정트리를 생성할 때는 
1) 각 트리마다 전체 데이터에서 랜덤하게 샘플을 뽑고 (중복 허용) 
2) 각 노드에서 전체 features 중 일부만 랜덤하게 선택해서 분할하기 때문에 다양한 관점의 결정 트리들이 만들어지고, 이를 종합하면 폭넓고 안정적인 예측을 할 수 있다는 장점이 있습니다.

**피해야 할 상황**:
- 모델 해석이 필수
- 실시간 예측 필요
- 메모리 제약
- 단순한 선형 관계
- 데이터 매우 적음

**주의사항**:
- 하이퍼파라미터 튜닝
- 교차 검증으로 안정성 확인
- 과적합 방지 (max_depth, min_samples 조정)
- 불균형 데이터 처리 (class_weight)
- 학습 범위 밖 예측 주의
