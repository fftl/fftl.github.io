## 한 줄 요약
---
여러 공공 데이터를 수집하고, 수집한 데이터들의 연관 관계를 만들어 새로운 가치를 찾아보는 프로젝트입니다.
## 배경
---
공공데이터는 주로 지역, 시간 별로 기록되고 있는 데이터가 많고, 그러한 지역과 시간이 거의 동일한 기준으로 제공되고 있습니다. 그래서 다양한 공공데이터를 수집하고 연관지어 보다면 그 동안 알지 못했던 발견을 하거나, 알던 사실을 더 확실하게 파악할 수 있을 것 같다는 생각을 하였습니다.

## 목표
---
- Python, Pandas, SQLAlchemy 같이 데이터를 다루는 툴에 익숙해지기
- 데이터를 보는 눈 기르기

## 사용 기술
---
Python(Pandas, SQLAlchemy), MySQL, Airflow, BigQuery, Looker Studio 등

## 파이프라인 전체 흐름
---
API → MySQL → Pandas Transform → BigQuery → Looker Studio
